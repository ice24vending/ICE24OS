# Protocolo físico P10–P12 — conflictos, borrado local y campo

**Pendiente – responsable: Calixto Isaac Galeana Medrano (QA), con Técnico, Administrador del ámbito y Seguridad según escenario.** No ejecutado por el agente. Las pruebas automáticas no acreditan batería, cámara, almacenamiento lleno, sótano ni cierre del OS.

## Entorno y datos

Usar un Android/Chrome y un iPhone/Safari físicos con bloqueo de pantalla, más un segundo dispositivo para concurrencia y un escritorio para el administrador. Registrar modelo/OS/navegador/versiones; no fijar una selección definitiva de dispositivos (DEC-018 está fuera del gate). HTTPS con certificado válido; usar instalación local controlada o Preview solo si ADR-026 está firmado y protegido. No activar banderas remotas para estas pruebas.

Cuenta y sucursal ficticias, Técnico asignado, Administrador autorizado, al menos tres órdenes, plantilla/versiones conocidas, dos fotos antes/después y folios únicos por escenario. Registrar commit, origen, usuario/persona, cuenta, sucursal/zona IANA, orden, dispositivo, hora local/UTC, rowVersion inicial/final, vigencia de reserva/descarga, tamaño de archivos y cola. Nunca adjuntar tokens, contraseñas, cookies, llaves ni fotos de personas reales.

Conexión: (1) Wi-Fi estable para preparar; (2) modo avión y Wi-Fi apagado, confirmar petición fallida; (3) alternar red móvil/Wi-Fi y cortes de 10–30 s en entorno seguro; (4) recuperar conexión estable. No manipular equipo en movimiento ni entrar en áreas peligrosas buscando mala señal.

Antes de cada caso descargar explícitamente y esperar confirmación local. Guardado local no equivale a cierre servidor. Mantener abierta la pestaña: actualmente, cerrar navegador requiere reconexión para recuperar el alcance. La propuesta WebAuthn de otra rama no forma parte de esta versión.
