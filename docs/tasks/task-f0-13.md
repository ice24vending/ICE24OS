# TASK-F0-13 — Proveedores externos

## Resultado

En revisión. [ADR-019](../decisions/adr-019-integrations.md) selecciona Cloud Storage, ClamAV en Cloud Run, Resend y Mapbox, siempre detrás de adaptadores y con límites presupuestarios.

## Cambios y trazabilidad

Archivos: ADR, plataforma, registro y estado. Traza PRD integraciones/archivos y TRD 17–20/80. El escaneo sigue la arquitectura de referencia de Google Cloud.

## Validación y pendientes

Fuentes oficiales confirmaron Cloud Run/Cloud SQL/PostGIS, la arquitectura ClamAV, Mapbox, Resend y la región de México. Pendiente alta, cuotas, términos, DPA/privacidad, dominio de correo y prueba del escáner. No se contrataron servicios.
