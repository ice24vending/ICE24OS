# TASK-F0-04 — Cloud, región y entornos

## Resultado

En revisión. [ADR-015](../decisions/adr-015-platform.md) selecciona Google Cloud `northamerica-south1`, proyectos separados y cinco entornos; incluye topología, escalado a cero y un tope presupuestario reducido.

## Cambios y trazabilidad

Archivos: ADR, índice y estado. Formaliza TRD 18–20/80 y Architecture 50/59. Alternativas descartadas: AWS para el piloto, Render/DigitalOcean productivos, Vercel fragmentado, GKE y VM única.

## Validación y pendientes

Validación documental contra fuentes oficiales de Google Cloud. Pendiente Pricing Calculator, cuotas, compra de dominio y revisión de residencia/proveedores externos. No se aprovisionó infraestructura ni se generó costo.
